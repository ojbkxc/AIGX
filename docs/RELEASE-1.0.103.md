# v1.0.103

## 这次更新的主要内容

### 模型管理「上下文 / 输出」现在对全部供应商生效

以前只有 models.dev 认识的那批模型有值，**小浣熊、Trae、Antigravity 这类账号型供应商的模型，这两列永远是空的** —— 明明上游自己申报了上下文窗口和输出上限，网关却没读。

根因是两处断链：
1. 账号目录刷新（`/api/account-sessions/catalog/sync`）成功后，只把结果写进账号快照，**从没转投给模型元信息层**，元信息层去查 provider 汇总表永远查不到
2. 目录内部字段叫 `context_length`，元信息层只认 `maxInputTokens`；输出上限在解析阶段就被丢掉了；小浣熊的真实键 `context_window` / `max_tokens` 也不在识别表里

修完之后（线上实测）：小浣熊 10 个模型从两列全空变成 `1000000 / 100000`，Trae、Antigravity 的模型也补上了。原来就正常的 `openai_compatible` 那批，值逐项没变。

顺带：重启后账号目录能从 KV 复活，不用等下一次手动刷新。

### 破甲控制台能套上预设的模型从 62 个变成 189 个

预设库里只有 19 家厂商的内容，而线上跑的是产品名（`claude-sonnet-4-6`、`gemini-2.5-pro`），预设写的是 `opus v2`、`Gemini-4-Argon` —— 两套命名没有公共子串，所以「按模型自动套用」对绝大多数模型都不生效。

现在加了厂商族映射（`Anthropic` → `claude/opus/sonnet`、`Google` → `gemini/gemma` 等 20 家），再加一层通用兜底。覆盖率 62/137 → 189/196。通用兜底可以在设置里关掉 —— 它会前插约 6KB 正文到该模型的每次请求上，小上下文模型会吃预算。

### 请求被上游判「非法客户端」的问题

Trae 通道多层修复：认证头（`Cloud-IDE-JWT` + 两个 token 头）、按账号 `variant` 分两套 UA、13 个客户端身份/渠道头、凭证里的 `uid`/`deviceId`/`machineId` 转成对应头、`base_url` 指向网页站导致的 404、空文本消息的 `content` 形态、工具参数的字符串形态。

### 客户端为空的日志不再显示 `unknown`

以前没识别到客户端就写 `unknown`，于是统计里多出一个根本不存在的「客户端 unknown」。现在没读到就是空，界面显示 `—`；历史数据读的时候自动折成空，不回填、不猜。

### 请求日志补上「供应商」列

后端从来没有这个字段，所以这列一直显示 `—`。现在按 A2A 的口径补上：渠道型取协议族，账号池型取账号的上游家（`trae`、`xiaohuanxiong` 等）。历史记录仍是空（当时没记），新记录有值。

### AI 运维按对话形态重做

左栏会话历史、右边消息流（840px 列宽）、输入区（附件行 + 模型/等级胶囊 + 发送/停止）、右上设置抽屉。**AIGX 自己的东西都保留且能用**：请求调试面、人工审批卡、渠道锁定、流式阶段指示、思考强度。

### wasm 数据面请求挂死

插件流失败时错误只写进 sink、不写终点，而消费方自己持有同一个 sink 的 sender 克隆，`recv()` 永远不会返回 `None` —— 于是那条检查错误的分支永远走不到，请求无界挂到客户端超时。真正触发它的是测试夹具的内存布局缺陷：输入缓冲区和应答区相邻且都不限长，超过 4 KiB 的请求会把自己的应答覆盖掉。两处都修了，同一用例耗时 180 秒 → 2~4 秒。

## 顺手修掉的

- 签到插件任务的失败被静默吞掉（判据写错，`2 > 3` 不成立）
- 签到记录快速翻页时旧响应覆盖新响应；清空记录发两次请求且页码是旧的
- 回放左栏把「未记录」显示成「失败」，同一行在日志页显示「—」
- 账号名被当 i18n key 查表（账号名叫「保存」会在英文界面显示成 Save）
- 福利动作的加载态是单值，同时点两个按钮时先返回的会把另一个解锁
- 限流填 0 变成「一律拒绝」（提示明明写着 0 = 不限制）
- `success_rate` 是 0~1 比例却当百分数用，供应商成功率恒显示 `0.x%` 且恒红
- 关掉「供应商」列后整表错位（Thead 过滤了、tbody 没过滤）
- `Security` 页的 `<colgroup>` 嵌在 `<thead>` 里，列宽设置全失效
- CSV 导出遇到裸 `\r` 会把一行裂成两行
- 拖列宽途中卸载组件，监听不摘、对已卸载组件落盘
- `ConfirmDialog` 的 `onConfirm` 同步抛错会变成未处理异常、弹窗不关还没提示
- 表单组件 id 从 label 文本派生，同页同 label 会撞 id
- SSE 多行 `data:` 拼不起来、`event: error` 被忽略、非流式降级时正文被丢
- 编辑用户清空配额会把额度静默清零
- `Epay` / `Notify` 首屏读取失败后一保存就把已配好的参数覆盖成空
- `HH:MM` 校验对非 ASCII 输入按字节切片会 panic
- config.toml 读坏时整份配置被静默丢弃且零日志
- 数据库连接串脱敏按第一个 `@` 切，密码里含 `@` 时后半段进日志
- 同一表单里「模型不支持读图」该提示却静默、模型列表拉取失败却清空已选
