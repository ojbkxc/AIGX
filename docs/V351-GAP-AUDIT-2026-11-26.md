# AIGX × Agent2API v3.5.1 差距审计汇总（2026-11-26）

> 基准：AIGX `main@54567dfd`（v1.0.111）↔ Agent2API v3.5.1（`C:\GitHub\Agent2API`，非 git 仓库）。
> 口径：**AIGX 的功能只能比 Agent2API 多，不能少；参照得不对的要修。**
> 生成方式：6 路并行只读审计 + 主控对高严重度项抽查核实。只读阶段未改任何源码。
> 证据标记：**[已核实]** = 主控亲自读过两侧源码确认；其余为审计员读过两侧源码后的结论，未经主控二次核实；「待核实」= 审计员未能确认。

## 0. 结论

- 大部分功能已对齐或是超集（账号列表/分页/筛选/导出、签到排程、标题路由、压缩路由、视觉兼容、云同步、代理池、工具服务、更新链路等）。
- **确认的缺口 34 项，参照错 13 项**。最该先修的是三类：
  1. **错误策略停在上游旧版 v1**（影响每一次请求失败后的行为，见 C-R1）
  2. **插件宿主 4 项能力未实现 + 2 项契约参照错**（合法上游插件装不上或跑不通，见 B-P、C-P）
  3. **订阅 provider 整块缺失**（上游内置 3 家，AIGX 注册表为 0，见 B-A1）
- 仓库 `docs/` 下的多份对齐台账与现状不符（见 §5），不能再当依据。

## 6. 工程事实（影响修复方式）

- **本机不能编译 Rust**：无 MSVC 工具链（无 `C:\Program Files\Microsoft Visual Studio*`、无 `cl`），PATH 上的 `link` 是 Git 自带的 MSYS 版本，`cargo check --locked` 以 exit 101 失败。`AGENTS.md` 的「本地不编译 Rust」属实。本地能跑：`cargo fmt --all -- --check`（7s）、`tsc --noEmit`（33s）、`npx vitest run`（84s）。
- **基线已有 1 个前端单测失败**：`frontend/src/pages/PurgeConsole.test.ts:545` `TypeError: default.resolve is not a function`（`import path from 'node:path'` 在 jsdom/ESM 下失效）。754 过 / 1 挂，非本轮引入。
- **CI 没有 `concurrency` 配置**：并发 push 会叠加运行，每次 6 组 feature check + 30 分钟 cargo test + 2 套 e2e。
- **`static/` 入库且有漂移检查**：并发前端改动各自重建会撞车，重建必须串行。
- **C 盘仅剩约 6G（95%）**。
- **共享文件热点**：`src/main.rs`（470 处路由注册）、`Cargo.toml`/`Cargo.lock`、`frontend/src/i18n/{zh,en}.json`（各 5824 行）、`frontend/src/types/index.ts`、`frontend/src/api/index.ts`、`frontend/src/App.tsx`、`src/account_session/registry.rs`、`frontend/src/lib/addAccountConfigs.ts`。
- 测试盲区：`src/graphql`、`src/oauth`（github/google/linuxdo）、`src/web` 零测试；`src/payment` 的 stripe/order_store、`src/db` 迁移层无测试。
- 文档失实：`CLAUDE.md:146`「不支持单元测试」（实有 2703 处内联测试 + 755 个 vitest 用例）；`AGENTS.md:19`「工作区含 aigx-net」（`Cargo.toml` members 只有 `.`）；`AGENTS.md:98`「rust-matrix 4 组合」（实际 6）；`CLAUDE.md` 称 React 19（package.json 是 18.2）。
